# Исследовательские профили пилота

`monstera_deliciosa.research.json` — результат сверки открытых справочных страниц и разрешённых Wikidata snapshots для личного некоммерческого пилота. Это данные для проверки будущего профиля, не опубликованный Golden Record.

- `facts` содержит значения, ссылки на разделы источников и состояние проверки; `localized_text_evidence` связывает EN/PL-тексты с этими фактами.
- `unresolved_conflicts` сохраняет расхождения рекомендаций, `unknown_or_unverified` — пробелы. Пустые параметры нельзя заменять значениями по умолчанию.
- Для трёх Wikidata entities сохранены реальные HTTP snapshots, revisions и SHA256. Для care-страниц сохранены только краткие собственные исследовательские заметки: исходные тексты/фото не зеркалировались, SHA256 страницы неизвестен и обозначен `null`.
- RHS-карточка и RHS-гайд — один независимый донор. Три entities Wikidata также один донор.
- `publishable=false`, `canonical_profile_ready=false`; ограничения перечислены в `release_blockers`. Допуск источников к производственному хранению/обработке этим файлом не утверждается.

Копия JSON хранится в `knowledge-base/staging/catalogue.sqlite`, таблица `plant_profile_research` (ключ `monstera_deliciosa`, SHA256 файла). Таблица отделена от `catalogue_drafts`: существующий экспорт не выдаёт исследовательский профиль за готовый care profile. Проверенная запись ухода в основном пилоте по-прежнему отсутствует.

Для выпуска нужны разрешённые исходники и полевая provenance, сверка таксона/синонимов, решение конфликтов, параметры/применимый fallback, animal-specific safety, связанные ConditionProfile, языковая и каноническая/семантическая проверка, затем публикация KB release.
