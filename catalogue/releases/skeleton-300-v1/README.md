# Базовый каталог: 606 растений

Статус: импортированные данные для собственной базы; не опубликовано в Supabase,
редакционная проверка не завершена. В каталог включены все
валидные популярные комнатные виды (606 видов: исходные 300, 222 ранее отсечённых лимитом
300 и 84 дополнительных популярных вида из Plantfolio/монотипных родов). Добавлено поле `watering`
из Plantfolio (`plantfolio-common-plants`) и полные польские описания (`descriptions.pl = 606/606`:
190 оригинальных статей польской Wikipedia + 416 переводов с английской Wikipedia по лицензии CC BY-SA 4.0). Без полного профиля болезней.

- `plants.json` — карточки с научным именем, названиями EN/PL, поисковыми aliases,
  описаниями, основным изображением, интервалами полива по сезонам (`watering`) и происхождением каждого блока.
- `media/` — скачанные изображения и metadata; приложение не должно зависеть от
  внешних URL при показе фотографий.
- `coverage.json` — фактическое покрытие (`description_en=606`, `description_pl=606` (`190 native + 416 translated`), `common_names_en=407`, `common_names_pl=430`, `watering_total=606`: 278 `species_exact`, 16 `species_synonym`, 222 `genus_representative`, 90 `botanical_group_representative`, `missing=0`), отсутствующие поля и исключённые кандидаты.
- `manifest.json` — контрольные суммы данных и изображений.
- `validation.json` — независимая проверка целостности и совпадения JSON/SQLite/Plantfolio.
- `discovery.json` — воспроизводимый набор кандидатов и источник категории.

Научное имя — P225 Wikidata при ранге species. Это не отдельная сертификация
принятого имени Kew/WCVP. Распространённые названия берутся из P1843, labels, явных формулировок вступления Wikipedia и переводов устоявшихся польских названий;
извлечённые из текста и переведённые названия сохраняют привязку к ревизии статьи и требуют редакционной проверки.
Поисковые aliases хранятся отдельно, поскольку могут включать научные синонимы.
Отсутствующее обиходное название не заменяется придуманным переводом.

Описания — исходные вступления Wikipedia (EN/PL) либо переводы вступлений английской Wikipedia на польский язык (`translation_source_language: "en"` при отсутствии собственной статьи в `plwiki`, с сохранением `source_revision`, ссылок на историю и атрибуции по CC BY-SA 4.0); они могут быть длиннее будущего текста
карточки и требуют редакционной проверки. `language` сохраняет реальный язык текста.
Фото проверены по metadata лицензии; `species_visual_review: pending` означает,
что соответствие и пригодность каждого изображения для главной карточки ещё
не подтверждены визуально. Отдельная атрибуция монстеры переиспользует ранее
проверенный `catalogue/manifests/pilot-media.json` при совпадении текущей лицензии.

## Воспроизведение из корня проекта

```sh
python3 knowledge-base/pipeline/import_catalogue_300.py --offline
python3 knowledge-base/pipeline/validate_catalogue_skeleton.py
python3 -m unittest discover -s knowledge-base/tests -q
```

Offline-пересборка требует сохранённых `knowledge-base/raw/catalogue-300/` и `media/`.
Сырые API snapshots и SQLite staging игнорируются Git. Для нового сетевого запуска
передать `--user-agent` с настоящим публичным контактом оператора. Существующий кеш
не обновляется автоматически; новый релиз требует отдельного каталога снимков.

## Атрибуция

Wikidata structured data: CC0. Тексты Wikipedia: CC BY-SA 4.0, с URL статьи,
revision/history и указанием авторов Wikipedia в каждой записи. Сохранить эти сведения
при показе/распространении; переводы и редакции соответствующего текста должны
соблюдать условия share-alike. Фото имеют индивидуальные лицензии, авторов и ссылки.
Лицензия данных не задаёт лицензию исходного кода приложения.
