# Задачи простого MVP Narat

**Редакция 2026-11-09.** [Spec](spec.md), [решения](../../docs/validation/spec-simplification-2026-11-09.md). 151 задача в очереди: 14 отмечены, 137 открыты; из них T172–T174 — 3 отдельные необязательные задачи комнат, не блокирующие MVP. 23 снятых ID отдельно. Из отмеченных 12 — прежняя приёмка неизменённого фундамента, T156 — только завершённое документальное решение; T161 — локально принятый серверный пакет (PostgreSQL/Deno), без live/API routing/client приёмки. Это не процент готовности продукта.

## Порядок и приёмка

- Для двух параллельных сессий подготовлены [план и задания A/B](../../docs/parallel/README.md) и [карта всех 137 открытых ID](../../docs/parallel/allocation.json): A — iOS/интеграция, B — сервер/данные/контракты. Это назначение ответственных, не приёмка и не новые зависимости; смешанные задачи закрываются после обеих частей. T172–T174 остаются необязательными и не запускаются в MVP-очереди.
- Четыре этапа: распознавание → диагностика → рекомендации → уход. Каталог и identification-only — короткие альтернативы, не обязательные дополнительные шаги.
- T156 определяет простой формат; прежний OPEN-PLAN больше не блокирует. Лечебные цепочки/AI-динамика/комнаты/дополнительные фотофункции и универсальный pipeline не входят в MVP.
- T155 сохраняет родительский ID, но выполняется четырьмя проверяемыми срезами T157–T160. Не запускать интеграцию на старом machine contract и не закрывать родителя по Markdown-правке.
- T148 остаётся незавершённой редакционной приёмкой данных; затем T149/T150/T151 с нужными срезами контрактов. Удаление минимального gate не делает T148 выполненной.
- Имена уже запланированных `full_plan`/`FollowUpReminderTests` файлов могут сохраняться; их объём задаётся текущей задачей, а не старым названием.
- `[X]` требует реализации и нужных проверок; снятие объёма не выполнение. Исторические T017/T041/T147/T152 не доказывают новый пользовательский маршрут.
- Применённые миграции не переписывать; forward upgrade сохраняет владельцев, историю, фото и расход. Fixtures, Simulator, реальные данные и живые интеграции указывать отдельно.
- `[P]` обозначает только независимость файлов после готовых предпосылок, а не разрешение автоматически запускать субагентов.
