# Вне MVP — решения 9 ноября 2026

Этот список не является обязательством следующего выпуска и не блокирует MVP. Источник решения — [принятое упрощение](../../docs/validation/spec-simplification-2026-11-09.md).

| Возможность | Статус / сохранённая польза |
| --- | --- |
| Универсальные лечебные последовательности, стадии и переходы | v2 по потребности; MVP: действия сейчас и следующая проверка. |
| AI-сравнение динамики нескольких фото | v2; MVP: обычная повторная диагностика. |
| Комнаты и фильтры по комнатам | Отдельный возврат простой группировки запланирован в T172–T174: название, список, фильтр; без условий/AI/влияния на уход. Не блокирует MVP; текущий runtime остаётся плоским до приёмки. [Контракт](contracts/simple-rooms.md). |
| Экспорт фото, выбор главного из журнала, специальное сравнение | v2; MVP: личные/контрольные фото и просмотр истории. |
| Универсальный сбор/synthesis/pipeline и полные профили | v2; MVP: ручные проверенные карточки, валидатор и импорт. |
| Сезонный override/расширенные коэффициенты | v2; MVP: только применимые опубликованные правила. |
| История пересчётов и отдельный экран причины | v2; MVP: текущая дата и короткое основание. |
| Камера света, post-analysis опрос/scores, товарный подбор/отзыв, выбор мест, отчёты, deleted-guest fallback | Отменены, не обещаны для v2. |
| Распределённые claims trial-уведомлений, отдельный durable funnel outbox | Удалены из целевой архитектуры; локальный opt-in reminder и неблокирующие события достаточны. |

Исторические комнаты/планы/фото не удаляются из данных из-за переноса функций. Применённые SQL сохраняются; целевой runtime очищается через T155/T157–T160. Подробные остатки OLD-01–07 перечислены в аудите, они не означают актуальную возможность приложения.
