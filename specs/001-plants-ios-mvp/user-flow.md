# Narat — пользовательский путь

Редакция 2026-11-09; нормативные правила — [spec.md](spec.md).

**Проверить растение → фото → недостающие свет/полив/дренаж → один анализ → вид, вероятная проблема/неопределённость и действие сейчас → сохранить → следующая проверка, напоминание и журнал.**

- До бесплатной пользы нет регистрации/оплаты. Нет обязательного выбора намерения, отдельного экрана проверки перед сохранением или дополнительного опроса после анализа.
- Каталог позволяет добавить известный вид без фото/опроса. Определение только вида — доступная альтернатива без диагностики; подтверждение вида не запускает второй AI.
- Сохранение из результата: Apple/Google → карточка; Free до трёх растений, paid без лимита. Ошибка/отказ сохраняет ввод; повтор не создаёт дубль.
- Гостевой результат живёт семь суток после успеха. После удаления — обычное добавление без TTL-экрана, восстановления из кеша и скрытого анализа. Постоянная коллекция сохраняется.
- Простые рекомендации дают действия и условие/дату следующей проверки. Включение ухода не является отметкой выполнения. Повтор обычной проверки — только по применимому правилу; первая помощь допускает один обоснованный контроль.
- Фото/наблюдение контроля можно сохранить без AI. Новая диагностика того же растения использует известные условия/фактическую историю без вопросов; отдельной AI-оценки динамики нет.
- Карточка содержит условия, фото, прежние результаты и журнал. Ошибку ухода можно отменить/исправить, в том числе offline. Пустой день не означает здоровье.
- Неприменимые рекомендации ставят будущие задачи/уведомления на паузу до явного обновления. История не меняется; недостающие данные не позволяют снять паузу.
- Free=3 и paid/trial=100 анализов в общем месяце от регистрации; два starter раздельны. Цены/даты — из магазина. Покупка возвращает к запросу; недоступный совет не продаётся.
- После окончания подписки все автоматические задачи и напоминания остановлены; чтение/ручной журнал доступны. Новый Free-пользователь имеет базовый уход, бывший подписчик следует этому правилу expiry.
- Напоминания добровольны: по умолчанию 09:00 местного времени. Trial-напоминание локальное, также opt-in; единственная доставка на все устройства не обещается.

Необязательный [v2 и отменённое](deferred.md) не добавляют экранов или gates MVP. Формат ухода согласован; прежний OPEN-PLAN не блокирует работу.
