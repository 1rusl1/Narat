# Narat — пользовательский flow

**Редакция 2026-11-08.** Основание — spec.md. Полный lifecycle плана ожидает OPEN-PLAN, остальные правила ниже согласованы.

## Первый запуск и помощь

Выбор языка EN/PL → намерение «Помочь растению» → фото → только недостающие свет/обычная частота полива/дренаж → анализ → предварительный результат и первая помощь. Ответ «не знаю» допустим. Вход/покупка не предшествуют бесплатному результату; дополнительных вопросов после анализа нет. Повторная диагностика существующего экземпляра: новое фото + известные условия и фактическая история, без вопросов.

## Добавление для ухода

Намерение «Настроить уход» → скан вида либо каталог → подтверждение вида. Скан не диагностирует болезнь. Известные условия не спрашиваются повторно; каталог допускает сохранение без фото/опроса. После входа: до трёх растений Free, четвёртое требует подписку; paid без лимита. Комната необязательна. После сохранения показывается реальный доступный шаг, без выбора мест и без продажи отсутствующего плана.

## Гостевой результат

Семь дней после успешного анализа → обычное сохранение после входа. После удаления черновика → обычный новый flow без TTL-экрана и восстановления cached result; никакого автоматического скана или обновления starter. Постоянная коллекция не удаляется по гостевому сроку.

## Доступ

Две отдельные разовые стартовые попытки до входа. После регистрации Free=3 и paid/trial=100 анализов за месячный период от регистрации. Смена тарифа не меняет период и не возвращает потраченное. При исчерпании обычное объяснение доступной квоты/следующей даты до запуска.

Предложение подписки после бесплатной пользы, по запросу платного продолжения. Отказ сохраняет доступный бесплатный путь, успешная покупка возвращает к запросу. Два тарифа: месяц 49,99 zł, год 199,99 zł; добровольный 7-дневный trial года только при eligibility, фактические цена/даты из магазина.

## Уход и история

Today показывает актуальные активные задачи, прошлые факты — дневник. Выполнение/отмена/правка даты сохраняются надёжно и не дублируются. Неприменимый план → будущие задачи и reminders приостановлены до обновления; ручной дневник доступен.

Окончание подписки → автоматический уход и напоминания прекращены для всей коллекции. Растения, фото, история и прежние планы читаются, фактический уход можно записать/исправить/отменить вручную. Ни активная тройка, ни завершение старых планов автоматически не назначаются. Новое добавление без подписки возможно только при количестве меньше трёх.

## Что отсутствует

Камера света, дополнительные вопросы после анализа, месячный отчёт, выбор активных мест, подбор конкретных товаров и локальное восстановление удалённого гостевого результата. Базовые события аналитики не добавляют экранов и не блокируют действия. Полный формат/длительность/завершение планов обсуждается отдельно; пример «30 шагов» не является flow.
