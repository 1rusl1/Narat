# Narat — спецификация простого MVP для iOS

**Редакция: 2026-11-11.** Объём согласован владельцем по [аудиту](../../docs/validation/overengineering-review-2026-11-09.md). Это требования, не подтверждение реализации. [Принятые решения и границы этапа](../../docs/validation/spec-simplification-2026-11-09.md).

Актуальная очередь и границы первого живого прогона — в [критическом пути](critical-path.md).

## Пользовательский путь

1. **Распознавание:** пользователь снимает растение или выбирает фото; приложение определяет вид либо сообщает неизвестность. Известное растение можно добавить из каталога, здоровое — определить без диагностики.
2. **Диагностика:** то же фото и только недостающие свет/частота полива/дренаж дают вероятную проблему, здоровое состояние либо ограничение. Это один анализ, не два обязательных вызова.
3. **Рекомендации:** единый результат показывает действие сейчас, основание, условия и следующую проверку. До первой пользы нет регистрации или оплаты.
4. **Уход:** после сохранения доступны карточка, простые проверки, добровольные напоминания и журнал. Выполненное действие отмечает пользователь; при необходимости новое фото проходит обычную диагностику.

## Простой формат ухода

Рекомендация — короткий набор применимых действий, а не программа с заданной длиной. У каждого действия есть основание и условия. Следующая проверка имеет срок только если он обоснован базой и известной историей. Если дата неизвестна, показывается наблюдаемый признак без выдуманного таймера.

Включение ухода не отмечает действие выполненным. Обычная проверка повторяется по опубликованному правилу после фактической записи/наблюдения; первая помощь имеет один связанный контроль, если он обоснован. Нет лечебных стадий, автоматического продления лечения, определения выздоровления или перехода между программами. Смена вида/условий ставит неподходящие будущие задачи на паузу; явное обновление из базы заменяет только будущее, сохраняя историю. Недостаток данных не разрешает возобновить уход. При изменении опубликованного правила затронутое будущее перепроверяется без переписывания фактов.

Ранее отложенный OPEN-PLAN разрешён этим форматом; реализация и проверка ещё предстоят. Лечение, для которого необходима неподдерживаемая последовательность, не сокращается до опасного совета.

## Бесплатный и платный доступ

| Возможность | Free | Подписка / trial |
| --- | --- | --- |
| До входа | Одно определение вида и одна отдельная диагностика | — |
| Месячные фотоанализы после регистрации | 3 | 100 |
| Добавление в коллекцию | Пока растений меньше 3 | Без лимита |
| Рекомендации | Первая помощь и контроль, базовые проверки перед поливом | Дополнительные применимые действия ухода и обновления рекомендаций |

Общий месячный период — от регистрации постоянного аккаунта; смена тарифа не сбрасывает расход. Месяц 49,99 zł, год 199,99 zł; добровольный семидневный trial только для годового при eligibility. Показываются фактические магазинные цены/даты.

После окончания подписки автоматический уход/напоминания всей коллекции прекращаются. История, фото, прежние рекомендации и ручной журнал остаются. Это согласованное исключение для бывшего подписчика сохраняется; новый Free-пользователь получает базовый уход.

## Сценарии приёмки

Все сценарии MVP проверяются на английском; ID историй сохранены для трассировки.

| История | Независимая проверка |
| --- | --- |
| US1, P1 — распознавание и помощь | Фото → недостающие условия → реальный результат; healthy/unknown/error, повтор без вопросов, без входа/покупки до бесплатной пользы. |
| US2, P1 — сохранение | Каталог или результат → Apple/Google → один экземпляр → чтение после перезапуска; лимит 3, guest семь дней, изоляция владельца. |
| US3, P1 — платный доступ | Покупка/отказ/trial/restore/expiry; реальные права, сохранение контекста, новые рекомендации только при наличии данных. |
| US4, P1 — уход | Проверка → фактическая отметка → журнал/следующая дата; offline/restart/retry, отмена/правка, пауза. |
| US5, P1 — карточка | Исправление вида/условий, фото/анализы с датами и неизменённой историей; новое фото того же экземпляра. |
| US6, P2 — напоминания | Согласие/отказ, местный час, перенос/отмена, прекращение при expiry/неприменимости; локальное trial-напоминание без серверного claim. |
| US7, P1 — профиль и приватность | Квоты/подписка, выход/смена аккаунта, удаление и отказ в разрешениях без утечки данных. |

## Функциональные требования

- **FR-001**: Интерфейс, ошибки, напоминания, новые рекомендации и страница приложения для MVP — на английском.

- **FR-002**: Основной путь: «Проверить растение» → фото → только недостающие базовые условия → единый результат. До бесплатной пользы нет входа или покупки; после анализа нет вопросов.

- **FR-003**: Фото можно снять, выбрать из галереи или заменить без потери ответов. Короткая подсказка просит показать растение и заметный симптом; второе фото не обязательно.

- **FR-004**: До первой диагностики запрашиваются только неизвестные свет, обычная частота полива и дренаж; везде допустимо «не знаю». Ответы сохраняются для экземпляра и при перезапуске. Повторная диагностика использует новое фото и фактический журнал без вопросов. Частота полива не заменяет дату последнего действия; пропуск задачи не означает выполнение.

- **FR-005**: До входа доступны отдельные разовые успешные определение вида и диагностика. Диагностика показывает вероятную проблему, здоровое состояние либо неопределённость, основание и применимое первое действие. Ошибка и повтор доставки не расходуют попытку; вход/удаление черновика/окончание подписки не выдают её заново.

- **FR-006**: Читаемые фото, включая исходники больше 10 МБ, автоматически нормализуются и сжимаются. Непригодное фото, недостаток данных и техническая ошибка объясняются без выдуманного результата.

- **FR-007**: Видны ожидание, результат или ошибка с повтором без повторного ввода. Ожидание не сообщает о найденной болезни; результат обозначает предварительность вывода.

- **FR-008**: Вход доступен через Apple и Google; отмена сохраняет полученный результат текущего сеанса.

- **FR-009**: После входа сохраняются экземпляр, фото, условия и результат. Free добавляет только при размере коллекции меньше трёх; подписка снимает лимит. Ограничение объясняется до сохранения.

- **FR-010**: Повтор одного сохранения не создаёт дубль; разные экземпляры одного вида разрешены.

- **FR-011**: Коллекция — плоский список растений с именем, видом и личным фото при наличии. Неизвестный вид и отсутствие личного фото допустимы.

- **FR-013**: Карточка объединяет условия, рекомендации, журнал, фото и прежние анализы. Достаточно простого списка записей с датами.

- **FR-014**: Главное действие проверяет растение по фото. Дополнительно доступны определение только вида и каталог для добавления без диагностики. Новый анализ связывается с выбранным существующим экземпляром либо новым растением, включая неопределённый вид.

- **FR-015**: Подписка предлагается после бесплатной пользы при запросе платного продолжения или добавления сверх лимита. Показаны реальные цена/валюта/период, продление, условия trial и лимит анализов. Отказ сохраняет контекст и Free-путь; подтверждённая покупка возвращает к запросу. Недоступные рекомендации не продаются.

- **FR-016**: Тарифы польского магазина: 49,99 zł/месяц без trial и 199,99 zł/год с добровольным семидневным trial при eligibility. Фактические цена и даты берутся из магазина. Допустимо локальное opt-in напоминание за 24 часа до окончания trial; доставка не гарантируется, дата видна без уведомлений.

- **FR-017**: Подписка/trial открывает расширенные применимые рекомендации и их обновление, дополнительные виды ухода и сто успешных фотоанализов за месячный период от регистрации. Анализы вида и проблемы используют общую квоту; повторная диагностика — обычный анализ. Сборка рекомендаций и сохранение фото не расходуют её. Покупка pending/error не выдаёт доступ.

- **FR-018**: Покупку можно восстановить; одна подписка не раскрывает коллекцию другого аккаунта приложения.

- **FR-019**: Единый формат рекомендаций: что сделать сейчас, почему, условия выполнения и следующей проверки. Действия независимы; фиксированная длина программы и многоэтапные лечебные цепочки не требуются. При необходимости средства показывается только проверенное применимое вещество с подтверждёнными условиями использования.

- **FR-020**: Подтверждённый магазином доступ учитывает trial/продление/expiry/refund. Отключение автопродления не прекращает оплаченный срок. После окончания доступа автоматический уход и напоминания всей коллекции останавливаются; данные, прежние рекомендации и ручной журнал с исправлением/отменой остаются. Повторная подписка не активирует неподходящие рекомендации.

- **FR-021**: Из профиля открывается стандартное управление подписками App Store.

- **FR-022**: «Сегодня» показывает активные сегодняшние и просроченные проверки, растение и добавление. В пустой день видна следующая известная проверка либо отсутствие расписания. Возврат после перерыва не отмечает уход и не требует выполнить все пропуски подряд.

- **FR-023**: Каждому разрешённо добавленному Free-растению доступны проверка перед поливом, применимые повторы, напоминания и журнал. Подписка открывает дополнительные применимые действия ухода и снимает лимит коллекции. Отсутствие одного факта не блокирует другие. После окончания подписки действует FR-020 даже для первых трёх растений; добавление на Free снова возможно только при размере меньше трёх.

- **FR-024**: Отметка выполненного действия создаёт одну запись журнала и согласованное состояние задачи, включая повторную доставку.

- **FR-025**: Ожидающее, сохранённое и ошибочное действие различаются. Ручной уход, отмена и исправление сохраняются без сети, переживают перезапуск и повтор. Параллельное изменение не теряет допустимый факт, пока растение не удалено.

- **FR-026**: Ошибочную отметку можно отменить; отменённое не считается выполненным.

- **FR-027**: Уход можно записать сегодняшней или прошедшей датой. Фактическая дата отличается от времени внесения; будущая дата не принимается.

- **FR-028**: Запись, отмена, исправление даты и условий согласуют следующие применимые проверки без дублей и переписывания истории. При неприменимости будущие задачи/напоминания приостанавливаются до явного обновления. Ручной журнал не снимает паузу и не возобновляет уход после expiry.

- **FR-029**: Для следующей проверки показаны текущая дата и короткое объяснение её основания. Отдельная история пересчётов дат не требуется.

- **FR-030**: Задачи учитывают местную дату; смена часового пояса не дублирует выполненные действия.

- **FR-031**: Вид и условия можно исправить без удаления экземпляра. История/фото сохраняются; прежний анализ остаётся связан с исходными условиями и помечается при их изменении.

- **FR-033**: Отказ в доступе к камере, галерее или уведомлениям не блокирует функции, которым это разрешение не нужно.

- **FR-035**: Напоминания включаются добровольно после появления применимых задач. Час по умолчанию — 09:00 местного времени, выбирается целый час. Смена часа/пояса обновляет будущие уведомления; пауза/expiry отменяют соответствующие напоминания.

- **FR-036**: Выполнение, отмена и перенос обновляют напоминания; одна задача не создаёт повторных уведомлений одного срока.

- **FR-037**: Контрольное фото сохраняется в истории того же растения независимо от права на AI. Прежние фотографии доступны для просмотра; специальный экран сравнения не требуется.

- **FR-039**: Профиль содержит аккаунт, подписку/квоту, час и включение напоминаний, управление подпиской, выход и удаление аккаунта.

- **FR-040**: Растение или аккаунт удаляются после подтверждения. Данные перестают быть доступны; до удаления аккаунта с подпиской объясняются последствия и доступно управление подпиской.

- **FR-041**: Растения, фото, результаты и персональные уведомления доступны только владельцу. Выход/смена аккаунта не показывает чужую историю и не отправляет чужую очередь.

- **FR-042**: Каталог ищет по научным и английским названиям и синонимам. При отсутствии проверенного локального имени используется научное; неизвестное имя не создаёт ложный вид.

- **FR-043**: Справочные сведения и фото имеют источник и допустимое основание использования; обязательная атрибуция доступна пользователю.

- **FR-044**: Рекомендации основаны на проверенных данных; пробел обозначается. Неизвестная токсичность не означает безопасность для животных или детей.

- **FR-045**: Новые сессии и запросы MVP используют английский независимо от языка устройства и прежнего выбора. Переключателя в интерфейсе MVP нет. Сохранённая история остаётся на исходном языке.

- **FR-046**: На экране результата можно исправить вид/условия и сохранить растение, не задерживая первую помощь отдельным обязательным экраном. Правка не запускает AI; неподходящие старые советы не выдаются за актуальные.

- **FR-047**: Ручной ответ отличается от неизвестности; отсутствующие сведения не угадываются и доступны для исправления.

- **FR-048**: После подтверждённого сохранения открывается карточка с реально доступной рекомендацией/проверкой либо журналом. Гостевые результат и фото доступны семь суток после успешного анализа, затем удаляются; новый обычный сценарий начинается без TTL-экрана, локального восстановления и скрытого AI. Сохранённая коллекция этим сроком не ограничена.

- **FR-049**: На первом экране главное действие — «Проверить растение», рядом доступны каталог и определение только вида. Обязательного экрана выбора намерения нет. После завершённого приветствия открывается «Сегодня»; незавершённый ввод сохраняется.

- **FR-050**: Определение только вида не диагностирует заболевание. После подтверждения вида можно дополнить только недостающие базовые условия; каталог сохраняется без фото/опроса. Применимая базовая рекомендация доступна до оплаты. Нет второго AI-вызова из-за подтверждения или сохранения.

- **FR-051**: Собираются только выбор способа, успех/ошибка анализа, сохранение, отметка ухода, показ подписки и подтверждённая покупка. Клиентская доставка неблокирующая, без отдельной постоянной очереди; потеря клиентского аналитического события допустима. Повтор event_id не дублируется; покупка фиксируется сервером, restore не покупка. Фото/диагнозы/ответы/свободный текст не передаются. Учёт доступа и расходов AI надёжен независимо от аналитики.

- **FR-052**: Каталог и проверенные рекомендации публикуются независимо. Показывается фактическое покрытие без минимального числа видов/проблем; здоровое, неизвестное и неподдерживаемое состояния не подменяются болезнью.

- **FR-053**: Для используемого факта/действия сохраняются значение, применимость, источник, основание использования, проверка и версия. Ручная подготовка достаточна; обязательного числа источников и полного профиля нет. Конфликт или непроверенное родовое обобщение не превращается в совет виду.

- **FR-054**: AI распознаёт вид/вероятную проблему из опубликованных IDs и сообщает ограничения. Рекомендации выбираются из базы; новые советы не генерируются на каждый запрос. Неизвестный ID отвергается; при недостатке основания нет специфического лечения.

- **FR-055**: Действия учитывают известную среду и ограничения: не советовать опрыскивание ради влажности, не назначать противоположные действия без условия выбора, не игнорировать явные признаки вредителя. Конкретный субстрат/состав рекомендуется лишь при проверенных данных; полный рецепт не обязателен для всех видов.

- **FR-056**: Интервал задаёт проверку, а не безусловный полив; действие требует наблюдаемого признака и совместимого метода. Нет проверенного интервала — нет автоматической даты; неизвестная последняя дата не означает «полить сейчас». Допустимо опубликованное сезонное правило с обозначенным календарным допущением, без универсальных коэффициентов и обязательного сезонного UI.

- **FR-057**: Действующее вещество не заменяет подтверждение применимости, дозы и способа использования. Если корректное лечение требует сложной последовательности, которую MVP не поддерживает, показываются ограничение и пригодная первая помощь; опасная сокращённая инструкция не создаётся.

- **FR-058**: Справка различает сведения о токсичности для кошек и собак, источник и неизвестность. Тяжесть/токсин не выдумываются; вывод о безопасности детей из этих данных не делается.

- **FR-059**: Английские формулировки действий, условий и чисел соответствуют проверенному источнику. Результат сохраняет версию базы; исправление/откат базы не переписывает историю.

- **FR-060**: Создание/явное обновление рекомендаций использует базу и текущие условия без AI и расхода фотоквоты. Расширенные рекомендации требуют подписку и применимые данные. Старый результат сохраняется; недостаток данных объясняется до оплаты.

- **FR-063**: При включении ухода создаются только применимые проверки по проверенному правилу; включение не является выполнением действия. Первая помощь может иметь один контроль по FR-066. После отметки обычной проверки создаётся следующая, только если её правило/срок известны и доступ активен. Завершение действия не означает выздоровление; лечебных цепочек, стадий и автоматического перехода к другому режиму нет.

- **FR-065**: Две разовые стартовые попытки учитываются отдельно. После регистрации Free=3, paid/trial=100 общих успешных фотоанализов за месячный период от регистрации, без накопления. На Free неиспользованный starter своего режима расходуется первым; на paid используется paid-квота. Смена тарифа/trial/restore/expiry не меняет период и не сбрасывает расход; Free и paid не суммируются. Остаток и дата обновления видны до запуска. Unknown сам по себе не выдаёт бесплатный повтор.

- **FR-066**: Первое применимое действие можно бесплатно отметить и пройти связанную проверку с наблюдением/фото без AI. Срок/признак — из базы; нет данных — нет выдуманного контроля. Повтор отметки не создаёт второй контроль; отмена снимает незавершённый контроль. При expiry автоматический контроль прекращается, ручной журнал остаётся.

- **FR-067**: При ухудшении или отсутствии улучшений доступны карточка, исправление условий и явная обычная повторная диагностика по квоте. Прежнее лечение не продлевается автоматически; пустой день и выполненные действия не доказывают здоровье.

## Критерии качества

Ранняя проверка — небольшой заранее выбранный набор поддержанных и неизвестных случаев плюс качественный UX-прогон. Публичный выпуск требует отдельного заранее зафиксированного протокола выборки и измерения SC-003/004; малая выборка не доказывает точность всего продукта. Числа ниже — цели, не достигнутые показатели.

- **SC-001**: На английском участник проходит фото → недостающие условия → результат и понимает первое действие; обязательный выбор намерения и вопросы после анализа отсутствуют. Критерии наблюдения задаются до UX-прогона.

- **SC-002**: На согласованном наборе фото/сети не менее 95% попыток завершаются за 30 секунд; таймаут не более 60 секунд. Ошибки учитываются, условия замера опубликованы.

- **SC-003**: На заранее размеченных определимых случаях точность вида не ниже 85%, основной причины не ниже 80%; отказ в определимом случае не засчитывается верным. Состав, размер и достаточность выборки фиксируются до публичного release eval в T118, без универсального минимума 200/100.

- **SC-004**: Не менее 90% первых действий соответствуют заранее допустимым действиям, не менее 90% непригодных/неоднозначных случаев явно обозначают неопределённость. Опасные рекомендации исправлены и повторно проверены до выпуска. Reference cases независимы от оцениваемой модели; правила выборки — SC-003.

- **SC-005**: Повтор, обрыв сети и перезапуск дают ровно одну подтверждённую запись действия без дублей задач; ожидающее не выдаётся за сохранённое.

- **SC-006**: Исправление вида/условий, отмена и правка даты сохраняют фото и фактическую историю, согласуют будущие применимые проверки.

- **SC-007**: На английском качественный UX-прогон подтверждает доступность условий, журнала и отмены из карточки. Найденные блокирующие ошибки исправлены; число участников и ограничения указаны, обязательной квоты 20 на язык нет.

- **SC-008**: Реальные StoreKit сценарии purchase/trial/pending/cancel/restore/expiry/refund соответствуют правам и ценам. Квоты проверены на первом/коротком месяце, смене тарифа и повторе. После expiry весь автоматический уход остановлен; история/ручной уход доступны.

- **SC-009**: A/B изоляция проверена для API, Storage, кеша/outbox и уведомлений; отказ в разрешении не блокирует независимые функции.

- **SC-010**: Каждая опубликованная справочная запись/фото имеет разрешённое использование и атрибуцию. Английский текст проверен редактором; неизвестное не заполнено догадкой.

- **SC-011**: Пользовательские сценарии проходят на английском, включая запуск при польском языке устройства. Старые результаты сохраняют исходный язык.

- **SC-012**: На английском доступны основная проверка, определение только вида и каталог. Каталог сохраняет без фото/опроса; четвёртый Free-экземпляр отклонён без потери ввода. Проверка маршрутов не требует фиксированного количества участников.

- **SC-013**: Пользователь понимает действие сейчас, условие выполнения и следующую проверку либо причину отсутствия срока. Нет обещаний многоэтапного лечения или автоматического выздоровления.

- **SC-014**: Правка вида/условий не расходует AI; guest claim до семи дней сохраняет исходные данные. На границе срока нет восстановления/TTL-экрана/скрытого скана; постоянная коллекция сохранена.

- **SC-015**: Доставленные базовые события соответствуют действиям; dedup исключает повтор, restore не покупка. Сбой/потеря клиентской аналитики не влияет на уход, покупку или расход.

- **SC-016**: Отчёт отражает фактическое покрытие и ограничения. Для опубликованных действий есть происхождение, применимость, права и проверенный английский текст; отдельный пригодный факт не ждёт полного профиля/минимального охвата.

- **SC-017**: Все рекомендации выбираются из проверенной опубликованной базы с версией. Сборка не вызывает AI; новый/неизвестный ID и непригодный факт не дают ложного совета.

- **SC-018**: Неподтверждённое вещество/применение не рекомендуются; неизвестная токсичность не безопасна. Нет товарного подбора/таймера; обновление базы сохраняет историю.

- **SC-019**: Первая диагностика спрашивает только недостающие базовые сведения; повторная и любой результат не содержат опроса, включая пустой журнал и неоднозначный снимок.

- **SC-020**: Включение ухода не отмечает действие. После записи создаётся только допустимая следующая проверка; отмена/исправление не дублируют её. При неприменимости/expiry будущие задачи и напоминания приостановлены; ручной журнал не снимает паузу.

- **SC-021**: Free добавляет до трёх, paid — без лимита. Одновременное добавление и replay не обходят cap. После expiry данные сохранены, автоматический уход остановлен, новое Free-добавление допускается только при count<3.

- **SC-022**: Отказ от покупки сохраняет первую помощь/карточку/доступный уход. Покупка возвращает к запросу; отсутствующие рекомендации не продаются. Срок контроля первой помощи не выдумывается.

- **SC-023**: Возврат после перерыва и пустой день не создают фактов/выздоровления. Повторная диагностика использует обычный режим; нет AI-сравнения, лечебных стадий или автоматического продления лечения.

- **SC-025**: События не содержат фото/диагнозов/ответов/текста; покупка подтверждена сервером. Нет отдельного durable analytics outbox, когортного или пользовательского месячного отчёта.

## Вне MVP и источники истины

В необязательный v2 перенесены лечебные последовательности, AI-оценка динамики, комнаты, экспорт/выбор главного фото/специальное сравнение, сезонный override UI, универсальный pipeline и журнал пересчётов. Это не зависимости выпуска. Снятые требования: FR-012/032/038/062; ранее снятые ID не переиспользуются. Полный перечень — [backlog](deferred.md).

Камера света, вопросы после анализа, товары/магазины и их отзыв, места ухода, месячный отчёт и восстановление удалённого гостевого результата отменены. Не возвращать их из старых схем/дизайна.

Фактическое покрытие данных — [каталог](../../docs/plant-catalogue-skeleton.md), технические поля — [план](plan.md) и contracts, реализация/остатки — [задачи](tasks.md), доказательства — [handoff](../../docs/handoff_status.md). Анализ требует сети; загруженная история читается offline, ручной уход надёжно ожидает отправки. Сервер/Apple/Google/AI требуют отдельных живых проверок.
