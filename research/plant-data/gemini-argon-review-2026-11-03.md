# Выборочная проверка отчёта Gemini Argon

Дата: 2026-11-03. [Оригинал](gemini-argon-report-2026-11-03.txt), [извлечённый JSON с отметкой unverified](gemini-argon-findings-unverified-2026-11-03.json).

Вывод: полезный список направлений, но выбор источников и готовность данных отчётом не доказаны. Импортировать его численные рекомендации в профиль нельзя без проверки первичных документов. Это выборочный аудит ключевых утверждений, а не полная проверка всех поставщиков, цен и лицензий.

## Существенные проблемы

1. **Количество источников скрыто группировкой.** «Три корпуса» включают NC State, UF/IFAS, Clemson/Wisconsin, UC IPM, Penn State, ASPCA — 6–7 организаций, плюс Kew, Wikidata, Commons, MRiRW. Это примерно 10–11 ресурсов с отдельными условиями и адаптерами, а не выбранная связка из 2–3 источников.
2. **Нет доказательств для большинства оценок.** В полученном тексте обнаружено 12 уникальных URL, преимущественно домашние страницы/каталоги. Отсутствуют точные публикации/таблицы для ряда чисел, реальные ответы коммерческих API и пункты условий, на которых основаны категорические запреты. Слова «проверено» и «эталон» сами по себе не evidence.
3. **Возможное смешение видов в диапазонах света.** Отчёт приписывает монстере оптимум 150–250+ FC. В найденном [UF/IFAS EP346](https://ask.ifas.ufl.edu/publication/EP346.pdf), стр. 2, раздел Acclimatization, Shipping, and Interior Care, 150–250 FC относятся к **Gynura aurantiaca**. Это не доказывает, откуда Gemini взял число, но этот документ не подтверждает его применимость к Monstera. Требуется точная видовая публикация; 100–150 FC как минимум и утверждение о фенестрации также не подтверждены текущей проверкой.
4. **Глубина подсушивания подменена.** [NC State Monstera](https://plants.ces.ncsu.edu/plants/monstera-deliciosa/), Description, говорит о верхней четверти–трети субстрата. Это не фиксированные 2.5–5 cm из JSON отчёта. Перевод требует размера горшка и обоснования. Тот же текст прямо описывает houseplant: объяснение расхождения света исключительно «уличным контекстом NC State» некорректно.
5. **Покрытие протоколов не доказано.** Сначала указано около 38/40, затем 39/40. Нет таблицы condition_id → точный документ → признаки/действия/противопоказания/контроль. Общее описание причины не равно готовому ConditionProfile. Утверждение о единственном пробеле mechanical_damage пока гипотеза.
6. **Бесплатное чтение превращено в нулевую стоимость базы.** В JSON одновременно указаны неизвестные/условные права университетского корпуса и нулевые обязательные платежи с perpetual_owned_database. Подтверждений такой лицензии нет. Неизвестные цены должны оставаться unknown/quote_required. Оценка LLM $15–50 не содержит модели, объёма и расчёта.
7. **Сравнение альтернатив неполное.** Open Plant Data фактически не оценён отдельной строкой, а OpenPlantbook — другой ресурс. В [официальном FAQ Open Plant Data](https://www.openplantdata.com/faq) есть разделы API и Excel export; нужно проверить образец/условия/договорную выгрузку. Это не рекомендация покупать его и не подтверждение бессрочных прав.
8. **Safety и алгоритмы требуют дополнительной проверки.** Human severity нельзя переносить на cat/dog. Предложенные +3 дня повторной проверки и semi-hydro числа — новые правила/кандидаты без достаточной валидации; не готовые параметры. Предложенное исключение для одного научного источника не принято автоматически. Не вся университетская рекомендация является первичным экспериментом.

## Что можно использовать сейчас

UF/IFAS — полезный кандидат для дополнительного поиска видовых публикаций. Сохранить разделение справочных фактов, пользовательского контекста и алгоритмов напоминаний. Проверять общий протокол по host scope. Сохранять taxon IDs, источники отдельных полей и нерешённые противоречия. Эти направления не означают утверждения поставщиков/лицензий или готового релиза.

## Следующий шаг

Выполнить узкую доказательную проверку вместо нового общего обзора: точные документы UF/IFAS для трёх видов, реальная выгрузка/образец доступных поставщиков, условия постоянного хранения и таблица численных утверждений монстеры с locators. Сравнить честные варианты из 2–3 конкретных источников и отдельно показать вспомогательные ресурсы. Если готовой базы не подтверждено, назвать результат собственным проектом сборки KB с неизвестной пока стоимостью.
