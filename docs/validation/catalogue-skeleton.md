## Живые API и Storage

На `narat-staging` публичный EN API вернул выпуск `skeleton-300-v1-en-85fcaba4`, 606 видов и две непересекающиеся страницы по 50 записей. Monstera отсутствует на первой странице и находится по `Swiss Cheese` и `Monstera deliciosa`. Запрос вымышленного вида вернул пустой результат. Карточки по slug `monstera_deliciosa` и taxon UUID `83f27806-3577-4bdc-9b18-222bedcf06d7` совпали. Отображаемое имя — `Swiss Cheese plant`. Текст описания совпал с EN-описанием под CC BY-SA 4.0.

Два публичных объекта Storage вернули JPEG. Размер и SHA-256 скачанных байтов совпали с метаданными API.
