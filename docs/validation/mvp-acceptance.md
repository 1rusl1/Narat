После потери ответа и повторного запуска точный retry оставил одну активную запись и одну квитанцию. После ещё одного запуска UI показал `Active`. `Undo` `b1f5b958-8f82-4209-8207-55dbc56895cb` создал одну отмену `07399679-b153-4e73-87f1-3650c1941104`. После перезапуска напрямую и через `My plants` тот же журнал показал `Undone`, совет и фото сохранились. B подтвердил те же UUID, один `care.record` и один `care.undo` в квитанциях.

PostgreSQL подтвердил отсутствие опубликованного профиля ухода для этой карточки. Итог у одного владельца — два задания, два экземпляра, две квитанции сохранения, одна запись полива и одна отмена.
