## Артефакт и незавершённое

Xcode реально собрал Release, подпись/UUID App+dSYM/Google IDs+callback/backend/public key и отсутствие 19 DEBUG-сентинелов проверены. Однако строгая проверка имени артефакта **FAIL**: compiled CFBundleName всё ещё Plants, DisplayName Narat. В системном диалоге действительно видно Plants. Уже принятый однострочный Info.plist fix оказался недостаточным из-за generated metadata. Этот bundle сохранён только как внутренний auth probe; итоговым tester-артефактом он не считается. Исходный failed helper и build log сохранены; app после сборки не редактировался.

Первый install helper остановился после установки на слишком сильном предположении о неизменности пути data container. Дополнительной установки не было: проверен SHA уже установленного binary, затем реальные поля UI подтвердили сохранность checkpoint. Это ограничение helper, не установленная потеря данных приложения.

Фото/ручная коррекция/новые C1–C2, физический iPhone, Apple и качество классификации здесь не проверялись. Сохранённая карточка остаётся доступной владельцу для дальнейшей технической приёмки; чужие данные не менялись. Проверка nonce не отключалась. Сбросов 0.
