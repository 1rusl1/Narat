# Источники данных для рекомендаций Narat

Проверено 19 ноября 2026. Подготовка источников идёт отдельно от очереди
уход → «Сегодня» → напоминания и не делает расширение рекомендаций
условием готовности версии тестировщику. Покупки остаются отложенными.

## Какие данные нужны

| Слой | Минимальные данные |
| --- | --- |
| Вид | Точный научный таксон, синонимы, сорт при необходимости, внешний ID, уровень совпадения с каталогом. Родовой пример не становится видовым фактом. |
| Рекомендация | Что проверить/сделать, наблюдаемое условие выполнения, комнатная применимость, ограничения и короткое объяснение. |
| Расписание | Отдельное основание срока следующей **проверки**, связь с фактическим поливом/наблюдением. При отсутствии основания — null, а не придуманное число дней. |
| Доказательство | Источник/URL, место в документе, дата, версия/хеш, поддерживаемые поля и состояние проверки. |
| Права | Точная лицензия/разрешение на автоматическое получение, хранение, преобразование и использование в приложении; атрибуция. Текст, фото и данные оцениваются отдельно. |

Для текущего ухода достаточно полива. На будущее можно независимо добавлять
свет, дренаж/субстрат, температуру, влажность и проверенные ограничения.
Токсичность кошек, собак и людей хранится раздельно; отсутствие данных — unknown.
Для персонализации уже используются условия экземпляра и фактический журнал;
сезонный override и оценку освещения камерой этот поиск не возвращает.

Фото имеют свои лицензии. | Справка для проверки фактов; не подключать массовый crawler. Для воспроизведения/выгрузки получить применимое разрешение. |

| [Wikidata](https://www.wikidata.org/wiki/Wikidata:Licensing) | Taxon IDs, названия, синонимы и внешние связи | Структурированные данные CC0; связанные тексты/фото отдельно. Уже есть в реестре проекта. | Подходит для сопоставления видов; сам по себе рекомендаций не даёт. |

Дополнительно проверена [FloraDB](https://github.com/FloraaDB/houseplants-botanical-floradb).

бесплатной коммерческой заменой Plantfolio.

## Фактический пробный разбор GrowSpot

Один запрос официального CSV, без ключа и без обхода ограничений. В файле
указаны snapshot **2026-11-16**, CC BY 4.0 и атрибуция GrowSpot.

- 3 525 строк, 174 091 байт, SHA-256
  `75b4fb55698495bda7f7efee9b17fe988a05679f2dc0680487252fff2267dc95`.
- 492 из 606 растений каталога совпали по уникальному научному имени
  после нормализации регистра/пробелов/Unicode, без подстановки рода или сорта.
- 114 оставлены без совпадения; дубли научных имён в источнике не обнаружены.
- Среди совпавших: low 18, medium 204, high 157, very_high 113.
- Все значения принадлежат четырём объявленным категориям.

Числа получены на живом файле, не из поискового описания. [Отчёт покрытия](care-data-sources-2026-11-19/growspot-coverage.json).
На странице автора tiers описаны как редакционные категории, а не измеренные
потребности каждого растения. Не превращать их в точные Lux-пороги или
вывод о здоровье. HF/GitHub mirrors имеют другие даты snapshot; не смешивать версии.
Файл с цитатами сторонних издателей из того же проекта здесь не импортировался.

Raw CSV и 492 сопоставленных кандидата находятся локально в
`/private/tmp/narat-care-sources-20261119/`; в приложение и Supabase они
не загружены. Утверждённые runtime-источники/права реестра не расширялись.

## Проверка уже имеющегося полива

Локальный выпуск каталога содержит watering у 606/606 записей:
278 species_exact, 15 species_synonym, 223 genus_representative,
90 botanical_group_representative. Это охват справочных данных, а не
606 проверенных автоматических правил ухода.

Все четыре SHA-256 файлов личного Plantfolio snapshot совпали с manifest;
commit `bbb364534cfbca28168085897ac9f2ff00a151a5`, usage
`personal_noncommercial_reference_only`. Его локальный LICENSE также
CC BY-NC-SA 4.0. Поиск не меняет существующие рекомендации или данные.

## Следующие действия

1. Продолжить утверждённые этапы ухода без ожидания нового наполнения базы.
2. Для будущего импорта света закрепить конкретный GrowSpot snapshot,
   атрибуцию и разрешённые операции в source-registry, проверить применимость
   совпадений и конфликты; 114 несовпадений не заполнять догадками.
3. Для широкого care-покрытия выбрать отдельное разрешение Plantfolio либо
   подходящий API-договор Perenual; платные подключения не оформлялись.
4. Любые новые карточки публиковать существующим versioned import только
   после предметной проверки. Получение файла, совпадение имени и лицензия
   не являются приёмкой рекомендации или расписания.
