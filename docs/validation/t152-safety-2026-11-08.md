# T152 — безопасный отказ вместо демонстрационного результата

Дата: 2026-11-08. Приняты все три среза через оркестратор (`t152-api-002`, `t152-ios-001`, `t152-live-disk-002`); задача **T152 закрыта** (не заменяет продуктовые задачи реализации T019/T038/T039/T149/T150).

## Реализовано

- API без подключённых persistence handlers возвращает HTTP 503 `INTERNAL_ERROR`, `retryable=true`, EN/PL. Нет фиктивного `committed` и пустой успешной sync-страницы; auth/account guards и переданные handlers сохранены. Функция `plants-api` развёрнута на стенде `narat-staging` (`ijwnyjdomwvnzmmcurkt`) с `verify_jwt = false` в `supabase/config.toml` (проверку JWT и возврат канонических EN/PL ошибок выполняет `defaultResolveRequestContext`).
- iOS по умолчанию не выдумывает квоту, фото, диагноз, совет или receipt. Care/scan и problem/scan показывают недоступность с повтором, возвратом и каталогом. Повтор сохраняет `operationId` и ввод; генератор изображений перенесён в test target.
- При сетевом отказе sync, включая отказ после промежуточной страницы и при full refresh, подтверждённый кеш/watermark сохраняются: страницы сначала собираются, затем применяются. HTTP 503 не очищает outbox. Сохранность `LocalOutbox`, подтверждённого кеша, watermark и изоляции владельцев проверена как на `inMemory`, так и на дисковом SQLite (`inMemory: false`) между четырьмя независимыми экземплярами `ModelContainer` с последующим идемпотентным replay.

API и конфигурация: `supabase/functions/plants-api/index.ts`, `supabase/functions/_shared/tests/persistence_unavailable_test.ts`, `supabase/config.toml`.

iOS: `ios/Plants/Data/Sync/SyncEngine.swift`, `ios/Plants/Features/Analysis/AnalysisFlowModel.swift`, `ios/Plants/Features/Analysis/CareQuestionsView.swift`, `ios/Plants/Features/Analysis/PreliminaryResultView.swift`, `ios/Plants/Features/Catalogue/GuestCatalogueView.swift`, `ios/Plants/Features/Onboarding/AddPlantRouter.swift`, `ios/PlantsTests/FirstHelpUnitTests.swift`, `ios/PlantsTests/SyncPersistenceTests.swift`, `ios/PlantsUITests/FirstHelpTests.swift`.
