## Общие компоненты

Семантическая палитра, роли текста, контейнер/заголовок секции, primary/secondary/destructive кнопки, сообщение статуса с доступным действием, фото/placeholder, строка условия, задача ухода, датированная запись журнала и ссылка на источник. Повторно используем существующие `CatalogueSavedConditionsView`, `CataloguePrivatePhotoView`, `PlantCareRecommendationContent` и компоненты результата. Обёртки не запускают новые чтения и не меняют lifecycle задач.

Новый theme-файл требует явного включения в Xcode target. Три исходных пользовательских изменения PBX/xcstrings сохраняются отдельно. Первый пакет может использовать уже включённый SwiftUI-файл и adaptive assets; отдельное добавление target membership выполняется минимальным патчем с сохранением пользовательского diff.

## Приёмка

- Для каждого этапа: реальные до/после PNG и просмотр представительных экранов в обеих темах и локалях; ошибки, ожидание и длинный текст входят в проверку.
- Dynamic Type, VoiceOver labels/порядок/действия, цели нажатия от 44 pt, контраст, Reduce Motion/Transparency и клавиатура. Критические статусы/даты/условия не обрезаются.
- Проверки существующих пользовательских сценариев по затронутым контролам. Успешная сборка сама по себе не подтверждает дизайн или сценарий.
- Тестовые скриншоты и живые интеграции фиксируются отдельно; без нового платного анализа или запроса разрешения ради скриншота.
- После каждого принятого этапа: handoff/tasks, отдельный commit и push. Общие T075/T077/T080/T098 остаются открыты до своей полной приёмки.
