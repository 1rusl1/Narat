# Staging diagnosis KB profile

This record covers **Monstera deliciosa** and possible overwatering for the staging photo flow. The action asks for a moisture and drainage check. The record has no calendar interval or treatment product. Publish it only in the documented test project after approval.

Each provenance hash is SHA-256 of the corresponding UTF-8 note below, with no terminating newline. The notes summarize the four public references reviewed on 11 November 2026.

- `rhs_monstera` — RHS Monstera genus guide lists M. deliciosa. It advises letting compost approach dryness between waterings and avoiding prolonged standing water. [Source](https://www.rhs.org.uk/plants/swiss-cheese-plants).
- `rhs_houseplant_health` — RHS describes yellowing as a general sign of stress. Assessment includes light, substrate moisture, and drainage. [Source](https://www.rhs.org.uk/plants/types/houseplants/how-to-help-a-poorly-houseplant).
- `ncsu_monstera` — NC State Extension describes M. deliciosa and advises allowing the upper portion of the potting mix to dry between waterings. [Source](https://plants.ces.ncsu.edu/plants/monstera-deliciosa/).
- `wisconsin_monstera` — UW–Madison Extension describes M. deliciosa and advises slightly drying its growing medium between waterings to avoid prolonged saturation. [Source](https://hort.extension.wisc.edu/articles/monstera-deliciosa/).
